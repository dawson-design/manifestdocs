**Decision.** The current plan lives in a plain-text file in the reader's home folder, one line per meal, so readers can edit it by hand.

**Why.** Testers wanted to copy last week's plan and change two meals, which a text editor already does well.

**Rejected.** An interactive planner in the terminal.
